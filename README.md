### SpringBoot Applications

This repo will contain the springboot apps done for learning purpose.

1. BookStore - simple CRUD app using mongodb docker container.
2. EcommerceApp - usage of CompletableFutures and Dockerizing the app and postgres DB.
3. VirtualThreads - to study about virtual threads and default platform threads.
4. ArticleService - end to end production grade springboot app using various tooling.
5. CustomerOrders - usage of ORM indexing
